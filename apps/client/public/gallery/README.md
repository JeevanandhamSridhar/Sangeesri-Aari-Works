# Gallery Images Folder

Place your gallery image files in this folder:
`apps/client/public/gallery/`

Examples:
- `apps/client/public/gallery/bridal-blouse-1.jpg`
- `apps/client/public/gallery/maggam-work-1.jpg`
- `apps/client/public/gallery/zardosi-design-1.jpg`

Once placed here, Next.js serves them at `/gallery/filename.jpg`.
You can update `apps/client/src/app/gallery/page.tsx` with these filenames!
